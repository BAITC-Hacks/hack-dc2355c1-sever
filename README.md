# Стартовый каркас агента — HackAlem AI

Каркас под agentic-решение: обёртка над OpenAI с кэшем и ретраями, цикл вызова
инструментов и Streamlit-демо. Задание вставляется в системный промпт, свои
функции — в `tools.py`.

## Старт (3 минуты)

```bash
pip install -r requirements.txt
cp .env.example .env          # вставьте OPENAI_API_KEY
python smoke_test.py          # проверит ключ, покажет доступные модели
```

`smoke_test.py` печатает список моделей, доступных вашему ключу — впишите
нужную в `MODEL` в `.env`. Имена моделей меняются, не угадывайте их.

```bash
python agent.py "посчитай 1250 * 0.12"   # разовая задача
python agent.py                          # диалог в терминале
streamlit run app.py                     # демо для защиты
```

## Файлы

| Файл | Зачем |
|---|---|
| `llm.py` | вызов модели: кэш на диск, 5 ретраев с backoff, учёт токенов |
| `tools.py` | инструменты агента, схема собирается декоратором `@tool` |
| `agent.py` | цикл «модель → инструмент → результат → модель», до 8 шагов |
| `app.py` | Streamlit-демо; сбоку видно, какие инструменты дёрнул агент |
| `smoke_test.py` | проверка ключа и моделей за 10 секунд |

## Свой инструмент

```python
@tool("Найти клиента в базе по ИИН.",
      iin="ИИН из 12 цифр")
def find_client(iin: str):
    return db.lookup(iin)
```

Всё: схема для API соберётся из сигнатуры, модель увидит инструмент сразу.

## Что здесь экономит время на хакатоне

**Кэш.** Повторный запрос с теми же аргументами возвращается с диска, не из API.
При отладке промпта вы прогоняете один и тот же вызов десятки раз — без кэша
$50 кончаются за пару часов. Отключается через `CACHE=0` в `.env`.

**Две модели.** `MODEL` — дешёвая, на ней отлаживаетесь. `MODEL_SMART` —
для финального прогона: `llm.chat(msgs, model=llm.MODEL_SMART)`.

**Ретраи.** На хакатоне API отвечает 429 регулярно: две с половиной тысячи
человек жмут enter одновременно. Пять попыток с экспоненциальной паузой.

**Ошибки инструментов уходят в модель текстом**, а не падают трейсбеком —
агент видит «Ошибка: ...» и пробует иначе.

**Учёт токенов** копится в `.usage.json`, `llm.usage_report()` печатает итог.

## Под защиту

Панель слева в `app.py` показывает каждый вызов инструмента с аргументами и
результатом. Это ровно то, что жюри agentic-трека хочет увидеть: агент
**делает действия**, а не пересказывает ответ модели.
